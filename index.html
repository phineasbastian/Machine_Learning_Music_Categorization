Milestones

Data Preparation

1,000 GTZAN tracks audited and stratified into train/val/test splits.

Feature Engineering

MFCCs, spectral features, and chroma used to represent audio.

ML Baseline

SVM achieved 75.3% accuracy.

Deep Learning

Custom CNN using spectrograms with parallel convolution branches.

AI Detection

Dual-head model for genre + AI classification.

DetectiveCNN Architecture

Parallel convolution branches detect harmonic (frequency) and temporal (rhythm) features before fusion into a shared representation.
